# Cryptocurrency Historical Data Analysis Using Python

## Project Description

This project analyzes historical cryptocurrency market data using Python. The analysis focuses mainly on Bitcoin and Ethereum to study price trends, daily returns, volatility, trading volume, correlation, and linear regression.

## Dataset

The dataset contains historical market data for 12 cryptocurrencies with 28,944 records and 8 columns.

Main attributes:
- Currency
- Date
- Open
- High
- Low
- Close
- Volume
- Market Cap

## Technologies Used

- Python
- Google Collab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

## Analysis Performed

- Data cleaning and preprocessing
- Bitcoin daily percentage change
- Ethereum six-month analysis
- Bitcoin closing price trend
- Trading volume distribution
- Mean and median analysis
- Bitcoin volatility analysis
- Normal distribution analysis
- Bitcoin and Ethereum correlation
- Linear regression
